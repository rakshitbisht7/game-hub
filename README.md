🎮 Game Hub

A modern Game Discovery App built with React and TypeScript, where users can explore popular games by genre, platform, and rating.

🔗 Live Demo: Game Hub

🚀 Features

🎨 Clean & Responsive UI with dark mode toggle

🔍 Search & Filter games by genre and platform

🏆 Game Ratings & Details displayed in real time

⚡ Built with React + TypeScript for type safety and scalability

🌐 Deployed on Vercel

🛠️ Tech Stack

React (with Hooks)

TypeScript

CSS 

Vercel for deployment

(API used for fetching game data, RAWG API)

⚙️ Installation & Setup

Clone the repo:

git clone https://github.com/your-username/game-hub.git
cd game-hub


Install dependencies:

npm install


Run the development server:

npm run dev


Open in browser:

http://localhost:5173/
